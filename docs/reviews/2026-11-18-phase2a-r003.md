## Limits
- **Output names.** The compiled ABI has empty output names, so two outputs of the same type in a swapped order cannot be told apart by the ABI lock. The tests check the meaning of each position (`getAgreement` returns `(client, provider, verifier, review_period, n)`, and so on).
- **The relay.** The reviewer's own report was not seen. If it contains findings beyond these six, they are not covered.
- **Not re-reviewed.** An R-004 would be the independent check of these fixes.
